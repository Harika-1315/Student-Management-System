# Saralvidhya Study Materials API

A FastAPI backend for authenticated PDF study-material management with PDF text extraction, OCR fallback, summaries, and quiz generation.

## Features

- User registration
- JWT-based authentication
- Protected PDF upload
- PDF text extraction using PyMuPDF
- OCR fallback using Tesseract
- Summary generation
- Quiz generation
- SQLite database
- Swagger API documentation
